## El caso: Comercial Arrayán Ltda. (ferretería ficticia de Chillán, cierre al 31-12-2025)

| Activo | $ | Pasivo y patrimonio | $ |
|---|---:|---|---:|
| Caja | 850.000 | Proveedores | 3.100.000 |
| Banco | 4.200.000 | Remuneraciones por pagar | 650.000 |
| Clientes | 3.600.000 | Préstamo bancario, porción corriente | 1.200.000 |
| Mercaderías | 5.500.000 | **Total pasivo corriente** | **4.950.000** |
| Seguros pagados por anticipado | 300.000 | Préstamo bancario, largo plazo | 4.800.000 |
| **Total activo corriente** | **14.450.000** | **Total pasivo** | **9.750.000** |
| Muebles y útiles, neto (2.400.000 − 480.000) | 1.920.000 | Capital | 10.000.000 |
| Vehículo, neto (9.000.000 − 1.800.000) | 7.200.000 | Resultado del ejercicio | 3.820.000 |
| **Total activo no corriente** | **9.120.000** | **Total patrimonio** | **13.820.000** |
| **TOTAL ACTIVO** | **23.570.000** | **TOTAL PASIVO + PATRIMONIO** | **23.570.000** |

- Resultado del ejercicio = ventas 40.000.000 − (costo de ventas 25.000.000 + remuneraciones 6.500.000 + arriendo 2.400.000 + depreciación 1.140.000 + seguros 300.000 + gastos generales 840.000 = 36.180.000) = **3.820.000**.
- Control previo: balance de saldos ajustados Debe = Haber = **62.030.000**. Depreciación del año = 10 % de 2.400.000 + 10 % de 9.000.000 = 1.140.000.
- Ecuación: 23.570.000 = 9.750.000 + 13.820.000 ✓ (todas las cifras revisadas el 02-11-2026).
- Clave: se clasifica por **plazo** (12 meses), no por el nombre de la cuenta; la depreciación acumulada **resta** del bien; cuadrar no basta (omitir la depreciación igual cuadra).
